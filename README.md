# IMDb Top 250 Movies Analysis Dashboard

## Project Overview

This project is an Excel-based data analytics dashboard created using the IMDb Top 250 Movies dataset.

The objective of this project was to transform raw movie data into meaningful insights and present them through an interactive and easy-to-understand dashboard.

## Tools & Technologies

- Microsoft Excel
- Power Query
- PivotTables
- PivotCharts
- Slicers
- KPI Cards
- Data Cleaning
- Data Visualization

## Dataset

The dataset contains information about IMDb Top 250 movies, including:

- Movie Title
- Original Title
- Genres
- Release Year
- Runtime
- IMDb Rating
- Number of Votes
- Metascore
- Worldwide Gross
- Budget
- Content Rating
- Countries of Origin
- Production Companies

## Data Preparation

Before creating the dashboard, I prepared the raw dataset for analysis.

The main steps included:

1. Cleaning the raw data
2. Handling missing and inconsistent values
3. Formatting columns
4. Preparing genre data for analysis
5. Creating PivotTables for different analysis requirements

## Analysis Performed

The dashboard analyzes movies from different perspectives:

- Total number of movies
- Average IMDb rating
- Total number of votes
- Average runtime
- Average metascore
- Top genres by number of movies
- Top movies by worldwide gross
- Top movies by number of votes
- Average IMDb rating by genre
- Movies by release decade

## Dashboard Features

The dashboard includes:

- KPI Cards
- Interactive Slicers
- PivotCharts
- Genre Analysis
- Rating Analysis
- Movie Popularity Analysis
- Worldwide Gross Analysis
- Release Year Analysis

## Key Insights

Some key metrics from the analysis:

- Total Movies: 250
- Average IMDb Rating: 8.31
- Total Votes: 192M+
- Average Runtime: 131.74 minutes
- Average Metascore: 76.75

## What I Learned

Through this project, I learned how to transform raw data into meaningful insights using Excel.

I improved my skills in data cleaning, Power Query, PivotTables, PivotCharts, KPI Cards, Slicers and Data Visualization.

Most importantly, I learned that data analysis is not just about creating charts. It is about identifying patterns, asking the right questions and presenting the findings in a way that is easy to understand.
